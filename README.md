# 失業手当のしくみ（shitsugyo-teate）

失業手当は何日分？いつから？仕事をやめた人の場面（年齢・雇用保険に入っていた期間・やめた理由）を見て、雇用保険法の決まりどおりの答え（もらえるか・何日分・いつから・いつまで）を選ぶ1日5問の学習ゲーム。正解したら「これは、どの決まり？」も選ぶ。

遊ぶ: <https://satou-aaaaa.github.io/shitsugyo-teate/>

- 「失業手当」は、雇用保険の「基本手当」のことです。答えは、e-Gov 法令検索の雇用保険法（<https://laws.e-gov.go.jp/law/349AC0000000116>）の条文（2026年5月13日施行の版）で確かめたことだけです。
- 人の名前・給料は作り話です。毎年変わる金額（賃金日額の上限・下限など）・法律の附則の一時的な決まり・ハローワークの運用（給付制限を何か月にするかなど）は答えにしません。
